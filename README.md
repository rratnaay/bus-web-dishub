# BIS Hub

BIS Hub adalah sistem informasi rute bus untuk Dinas Perhubungan. Aplikasi ini membantu masyarakat menemukan jalur bus, melihat urutan halte, mengecek estimasi perjalanan, dan meninjau peta rute. Admin dapat mengelola seluruh data layanan melalui dashboard.

## Teknologi

- Laravel 12 dan PHP 8.2+
- Blade dan Eloquent ORM
- MySQL
- Tailwind CSS
- Leaflet.js dan OpenStreetMap
- AOS (Animate on Scroll)

## Fitur

### Pengunjung

- Pencarian rute berdasarkan halte asal dan tujuan.
- Kolom pencarian dengan ikon lokasi, state focus, dan desain responsif.
- Hasil pencarian berupa kartu jalur: nomor jalur, warna, koridor, jumlah halte, dan estimasi waktu.
- Detail jalur bus dengan peta OpenStreetMap, marker halte, jadwal operasional, dan timeline perjalanan interaktif.
- Detail halte untuk melihat seluruh jalur bus yang berhenti di halte tersebut.
- Badge nomor dan warna jalur, misalnya B1, B2, B3, serta B5.
